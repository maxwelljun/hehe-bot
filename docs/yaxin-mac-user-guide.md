# 亚信全桌监控 macOS 使用说明

## 选择版本

- Apple M1、M2、M3、M4 及后续 M 系列：使用 `osx-arm64`。
- Intel 处理器 Mac：使用 `osx-x64`。

## 首次启动

1. 解压安装包，将 `YaxinMonitor.app` 拖入“应用程序”。
2. 确认已经安装 Google Chrome。
3. 双击 `YaxinMonitor.app`，程序会在默认浏览器打开本机控制页。
4. 保持“只读”模式，点击“启动监控”。
5. 在自动打开的专用 Chrome 中手动登录网站。
6. 控制页显示“已连接”和桌台数量后，再根据需要启用真实模式。

程序只监听本机地址 `127.0.0.1:17868`，控制页不会对局域网或互联网开放。账号、密码、Cookie 和登录令牌保存在专用 Chrome 用户目录中，监控程序不会写入日志。

## 后台运行

关闭控制页不会结束程序。再次双击 `YaxinMonitor.app` 会重新打开控制页，已经运行的监控不会重复启动。

点击控制页中的“停止监控”只停止监控服务，专用 Chrome 和控制程序仍会保留。点击“退出程序”才会停止监控并结束后台进程。

macOS 进入睡眠后无法继续监控。需要保持用户登录，并关闭系统自动睡眠。

## 数据目录

点击“数据目录”可打开：

```text
~/Library/Application Support/YaxinMonitor
```

Windows 与 macOS 使用独立数据目录，不会自动同步运行状态。首次切换设备前，应先停止原设备并核对网站订单记录，避免两个设备同时自动下单。

## 功能按钮

- “保存设置”：只保存当前设置，不启动监控。
- “启动监控”：启动服务并恢复本机上次保存的运行状态。
- “停止监控”：停止读取和自动下单。
- “暂停自动下单 / 恢复自动下单”：只控制新的自动订单；监控和已受理订单继续运行。
- “订单对账”：处理状态不明或待外部结算的订单。
- “重置状态并启动”：清空本机运行状态后重新开始，使用前必须核对网站订单记录。
- “检查更新 / 更新到 vX”：从授权服务器下载最新版本并替换本程序，详见“程序更新”。
- “回滚版本”：恢复到更新前备份的版本。
- “退出程序”：停止监控并结束后台进程。

已受理订单如果在洗牌、切换牌靴或程序重启前仍未观察到结果，会转为“待外部结算”。旧追注到此结束，该桌可以继续处理新订单；旧订单仍占用在途和风险额度。自 `1.5.1` 起，程序收到网站的本单结算推送后会自动结算并释放占用；确认超时的订单若该局开奖 10 秒后仍无本单结算推送，则自动判定未下注。只有断线或重启期间错过推送时，才需要在“订单对账”中人工处理。

## 程序更新

自 `1.6.0` 起，程序登录后会自动检查授权服务器上是否有新版本；有新版本时按钮显示为“更新到 vX”。

1. 先点击“停止监控”，并确认没有仍在处理的订单。监控运行时不能更新或回滚。
2. 点击“检查更新”或“更新到 vX”，确认后开始下载，按钮上显示下载进度。
3. 下载并校验完成后，程序自动替换 `YaxinMonitor.app` 并重启，控制页会自动刷新，重新登录即可。

程序会自动下载与本机匹配的版本（M 系列为 `osx-arm64`，Intel 为 `osx-x64`）。旧版本备份在数据目录的 `backup/YaxinMonitor-版本.app`，最多保留最近 3 个。新版本有问题时，停止监控后点击“回滚版本”即可恢复。

`YaxinMonitor.app` 必须拖入“应用程序”等可写目录后再运行；直接在“下载”文件夹或压缩包中运行时，macOS 会把程序放到只读的临时位置，无法更新。`1.5.1` 及更早版本需要手动安装一次 `1.6.0`。

## 无法打开

当前安装包使用临时本地签名，没有经过 Apple 公证。如果 macOS 首次启动时阻止打开，请在 Finder 中按住 Control 点击 `YaxinMonitor.app`，选择“打开”，再确认一次。后续可以正常双击启动。
