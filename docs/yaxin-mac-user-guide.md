# 亚信全桌监控 macOS 使用说明

## 选择版本

- Apple M1、M2、M3、M4 及后续 M 系列：使用 `osx-arm64`。
- Intel 处理器 Mac：使用 `osx-x64`。

## 首次启动

1. 解压安装包，将 `YaxinMonitor.app` 拖入“应用程序”。
2. 确认已经安装 Google Chrome。
3. 双击 `YaxinMonitor.app`，程序会在默认浏览器打开本机控制页。
4. 保持“只读”模式，点击“启动监控”。
5. 在自动打开的专用 Chrome 中手动登录网站。
6. 控制页显示“已连接”和桌台数量后，再根据需要启用真实模式。

程序只监听本机地址 `127.0.0.1:17868`，控制页不会对局域网或互联网开放。账号、密码、Cookie 和登录令牌保存在专用 Chrome 用户目录中，监控程序不会写入日志。

## 后台运行

关闭控制页不会结束程序。再次双击 `YaxinMonitor.app` 会重新打开控制页，已经运行的监控不会重复启动。

点击控制页中的“停止监控”只停止监控服务，专用 Chrome 和控制程序仍会保留。点击“退出程序”才会停止监控并结束后台进程。

macOS 进入睡眠后无法继续监控。需要保持用户登录，并关闭系统自动睡眠。

## 数据目录

点击“数据目录”可打开：

```text
~/Library/Application Support/YaxinMonitor
```

Windows 与 macOS 使用独立数据目录，不会自动同步运行状态。首次切换设备前，应先停止原设备并核对网站订单记录，避免两个设备同时自动下单。

## 功能按钮

- “保存设置”：只保存当前设置，不启动监控。
- “启动监控”：启动服务并恢复本机上次保存的运行状态。
- “停止监控”：停止读取和自动下单。
- “暂停自动下单 / 恢复自动下单”：只控制新的自动订单；监控和已受理订单继续运行。
- “订单对账”：处理状态不明订单并恢复对应隔离桌台。
- “重置状态并启动”：清空本机运行状态后重新开始，使用前必须核对网站订单记录。
- “退出程序”：停止监控并结束后台进程。

## 无法打开

当前安装包使用临时本地签名，没有经过 Apple 公证。如果 macOS 首次启动时阻止打开，请在 Finder 中按住 Control 点击 `YaxinMonitor.app`，选择“打开”，再确认一次。后续可以正常双击启动。
