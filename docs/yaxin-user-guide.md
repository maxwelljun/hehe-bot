# 亚信全桌监控使用说明

## 系统要求

- Windows 10/11 x64
- 已安装 Google Chrome
- 可以正常访问并登录 `https://www.yaxin868.com/`

程序是自包含单文件，不需要安装 .NET、Python、Node.js、ChromeDriver 或浏览器扩展。

## 首次使用

1. 解压 `YaxinMonitor-1.2.4-win-x64.zip`，运行 `YaxinMonitor.exe`。
2. 模式保持“只读”，点击“启动监控”。
3. 程序会使用独立用户目录启动 Chrome 并打开网站。请在 Chrome 中手动输入账号、密码和验证码。
4. 登录后等待主界面显示“已连接”和桌台数量。程序读取服务器下发的全部百家乐桌台，不需要滚动页面。
5. 先保持只读或模拟模式观察。桌台列表会显示牌靴、局号、最新走势和当前追注档位。

Chrome 可以最小化，但不能退出。Windows 用户会话需要保持登录；电脑休眠期间不会下注，恢复后程序会重新同步全部桌台。

## 页面一直 Loading

如果曾运行 `1.1.0` 或更早版本，并且亚信页面一直显示 Loading：

1. 先在监控程序中点击“停止”，再彻底退出旧程序。
2. 在专用 Chrome 中按 `Ctrl+Shift+R` 强制刷新；仍未恢复时关闭该 Chrome 后重新运行 `1.2.4`。
3. 等页面自行加载并登录成功后，再点击“启动监控”。

`1.2.4` 不再调用网站的 SystemJS 模块加载器，并会自动打开缺失的亚信标签页。登录后即使跳转到变化的业务域名，也会逐页检查并选择已经取得百家乐桌台数据的游戏页。网站拒绝订单时，运行记录会同时显示错误码及网站语言包提供的说明。现有登录资料和本地策略数据可继续使用，不需要删除数据目录。

## 策略设置

- 每桌分别计算最新庄闲走势。
- 和局不增加也不中断连续走势。
- “触发走势”可选择庄和闲、仅庄或仅闲。
- “连续次数”可设置为 `2–20`；只有最新结果首次达到该次数时触发。
- “方向”可选择反向或顺向。反向表示连庄买闲、连闲买庄；顺向表示连庄买庄、连闲买闲。
- “金额序列”支持 `1–10` 档，用逗号分隔，例如 `10,20,40`。每档必须是 `1–1000000` 的整数，金额档数就是最多下注次数。
- 软件允许配置的最小金额是 `1`；真实下注还必须满足目标桌台的闲/庄最低限额，不符合时不会发送订单。
- 任意一档获胜立即结束；最后一档仍失败也结束。
- 下注后的和局不消耗档位，下一局保持原金额。
- 同一条连续走势只触发一次，程序正常重启也不会重复。

默认策略仍是：庄和闲、连续 `6` 次、反向下注、金额 `10,20,40`。程序一次只运行一条策略。修改策略前必须停止监控；存在等待确认、等待结算或状态不明的订单时不能切换策略。

桌台列表默认按“最新走势”的连续次数从高到低排列，并在实时刷新时保留当前滚动行号。

## 三种模式

| 模式 | 行为 |
| --- | --- |
| 只读 | 读取全部桌台并推演策略，不向网站发送订单 |
| 模拟 | 完整记录模拟订单和结算，不向网站发送订单 |
| 真实 | 满足全部检查后向网站发送真实订单 |

修改模式、资金或策略设置前需要先停止监控。

## 启用真实模式

1. 点击“停止”。
2. 模式选择“真实”。
3. 设置触发走势、连续次数、方向和金额序列。
4. 设置“每日上限”和“在途上限”。任一数值为 `0` 时不能保存真实模式。
5. 设置下注安全余量，默认 8 秒。剩余时间低于该值会跳过本局。
6. 保持“下注及结算语音提醒”选中。
7. 点击“保存设置”，核对确认窗口中的完整策略和资金上限。
8. 点击“启动监控”。真实模式启动后默认暂停新订单，点击“恢复新订单”才会开始发送。

网站返回订单受理成功后，程序会播报桌台、方向、金额和“下单成功”，例如“桌台 3212，买闲 50，下单成功”。结算时播报“桌台 3212，本局投注获胜”或“桌台 3212，本局投注落败”；和局不播报胜负并保持当前档位。多桌同时结算时语音会依次播放。Windows 语音组件不可用时会退回不同的系统提示音。

真实订单全局至少间隔 3 秒发送。网站返回 `-96`“投注过于频繁”时，程序会将后续订单再延迟 10 秒；发送前会重新检查桌台局号、下注状态和安全余量，不会补发已经过期的订单。

## 后台运行

关闭主窗口会隐藏到系统托盘，不会退出程序。双击托盘图标可重新打开。托盘菜单可以打开窗口、暂停新订单或退出。

“暂停新订单”不会中断已经受理的订单；程序仍会等待结算并保存状态。

## 自动暂停

以下情况会自动暂停真实订单：

- 登录失效或 Chrome/网页连接中断
- 网站前端版本改变
- 全桌数据不完整或历史记录异常
- 订单确认超时，无法判断网站是否已经受理
- 网站返回验证码错误 `-140`
- 余额不足、桌台限额不符或达到资金上限

订单状态不明时不能自动恢复或补单。请先在网站订单记录中人工核对，再处理本地状态。

单个桌台出现跨靴或历史数据异常时，程序会隔离该桌并暂停真实新订单，但页面连接和其他桌台仍会继续监控，不会反复重连。订单确认超时后如果网站稍后返回确认，程序会自动恢复订单状态；新订单仍保持暂停，需核对后手动恢复。

“启动监控”会恢复上次保存的桌台、追注、未完成订单、当日累计金额和防重复状态。重启时发现的未完成订单会变为“状态不明”，必须先对账，避免重复下注。

确实需要放弃全部旧运行状态时，可以点击“强制启动”。确认后，程序会清空桌台、追注、未完成订单、当日累计金额和防重复状态，再以网页最新全桌数据重新判断；设置、运行日志和订单审计文件不会删除。网页最新结果恰好满足策略触发条件时可能重新生成订单，因此真实模式下必须先在网站确认没有仍在处理的订单。

如果保存策略时提示其他策略仍有未完成订单，请按提示处理：

1. “等待网站确认”表示订单刚发送，等待网站返回结果后再操作。
2. “等待开奖结果”表示订单已经受理，必须等待该局结算。
3. “状态不明”通常由程序重启或确认超时导致。停止监控，点击“订单对账”，逐笔核对网站订单记录后选择“确认未下注”或“确认已结算”。仍在等待结算或无法确认时选择“暂不处理”。

人工对账结果会保存在订单审计记录中。程序不会自动猜测订单结果，也不允许人工清除正常等待确认或等待结算的订单。

## 本地数据

点击“数据目录”可打开：

```text
%LOCALAPPDATA%\ScreenWatch\yaxin\
```

其中保存非敏感设置、每桌状态、订单审计日志和专用 Chrome 用户目录。程序不会把账号、密码、Cookie 或登录令牌写入日志。
