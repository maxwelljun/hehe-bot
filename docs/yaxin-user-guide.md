# 亚信全桌监控使用说明

## 系统要求

- Windows 10/11 x64
- 已安装 Google Chrome
- 可以正常访问并登录 `https://www.yaxin868.com/`

程序是自包含单文件，不需要安装 .NET、Python、Node.js、ChromeDriver 或浏览器扩展。

## 首次使用

1. 解压 `YaxinMonitor-1.3.0-win-x64.zip`，运行 `YaxinMonitor.exe`。
2. 模式保持“只读”，点击“启动监控”。
3. 程序会使用独立用户目录启动 Chrome 并打开网站。请在 Chrome 中手动输入账号、密码和验证码。
4. 登录后等待主界面显示“已连接”和桌台数量。程序读取服务器下发的全部百家乐桌台，不需要滚动页面。
5. 先保持只读或模拟模式观察。桌台列表会显示牌靴、局号、最新走势和当前追注档位。

Chrome 可以最小化，但不能退出。Windows 用户会话需要保持登录；电脑休眠期间不会下注，恢复后程序会重新同步全部桌台。

## 页面一直 Loading

如果曾运行 `1.1.0` 或更早版本，并且亚信页面一直显示 Loading：

1. 先在监控程序中点击“停止监控”，再彻底退出旧程序。
2. 在专用 Chrome 中按 `Ctrl+Shift+R` 强制刷新；仍未恢复时关闭该 Chrome 后重新运行 `1.3.0`。
3. 等页面自行加载并登录成功后，再点击“启动监控”。

`1.3.0` 不再依赖网站前端文件名白名单。每次连接会实际检查全桌读取、桌台状态、下注函数、限额数据和订单回执接口；检查通过后，即使 `index.xxxxx.js` 文件名再次变化也可继续工作。关键接口缺失时会暂停自动下注并保持页面连接，不会反复重连刷屏。现有登录资料和本地策略数据可继续使用，不需要删除数据目录。

## 功能按钮

- “保存设置”：只保存当前模式、策略和风控参数，不启动监控。
- “启动监控”：按当前设置启动，并恢复上次保存的运行状态。
- “停止监控”：停止监控服务，专用 Chrome 不会关闭。
- “暂停自动下单 / 恢复自动下单”：只控制新的自动订单；全桌监控和已受理订单继续运行。仅在真实模式运行时可用。
- “订单对账”：处理状态不明或待外部结算的订单，监控运行时也可使用。
- “重置状态并启动”：清空桌台、追注、未完成订单、当日累计金额和防重复状态，然后重新启动。使用前必须核对网站订单记录。

## 策略设置

- 每桌分别计算最新庄闲走势。
- 和局不增加也不中断连续走势。
- “触发走势”可选择庄和闲、仅庄或仅闲。
- “连续次数”可设置为 `2–20`；只有最新结果首次达到该次数时触发。
- “方向”可选择反向或顺向。反向表示连庄买闲、连闲买庄；顺向表示连庄买庄、连闲买闲。
- “金额序列”支持 `1–10` 档，用逗号分隔，例如 `10,20,40`。每档必须是 `1–1000000` 的整数，金额档数就是最多下注次数。
- 软件允许配置的最小金额是 `1`；真实下注还必须满足目标桌台的闲/庄最低限额，不符合时不会发送订单。
- 任意一档获胜立即结束；最后一档仍失败也结束。
- 下注后的和局不消耗档位，下一局保持原金额。
- 同一条连续走势只触发一次，程序正常重启也不会重复。

默认策略仍是：庄和闲、连续 `6` 次、反向下注、金额 `10,20,40`。程序一次只运行一条策略。修改策略前必须停止监控；存在等待确认、等待开奖结果或状态不明的活动追注时不能切换策略。

桌台列表默认按“最新走势”的连续次数从高到低排列，并在实时刷新时保留当前滚动行号。

## 三种模式

| 模式 | 行为 |
| --- | --- |
| 只读 | 读取全部桌台并推演策略，不向网站发送订单 |
| 模拟 | 完整记录模拟订单和结算，不向网站发送订单 |
| 真实 | 满足全部检查后向网站发送真实订单 |

修改模式、资金或策略设置前需要先停止监控。

## 启用真实模式

1. 点击“停止监控”。
2. 模式选择“真实”。
3. 设置触发走势、连续次数、方向和金额序列。
4. 设置“每日上限”和“在途上限”。任一数值为 `0` 时不能保存真实模式。
5. 设置下注安全余量，默认 8 秒。剩余时间低于该值会跳过本局。
6. 保持“下注及结算语音提醒”选中。
7. 点击“保存设置”，核对确认窗口中的完整策略和资金上限。
8. 点击“启动监控”。真实模式启动后默认暂停自动下单，点击“恢复自动下单”才会开始发送。

网站返回订单受理成功后，程序会播报桌台、方向、金额和“下单成功”，例如“桌台 3212，买闲 50，下单成功”。结算时播报“桌台 3212，本局投注获胜”或“桌台 3212，本局投注落败”；和局不播报胜负并保持当前档位。多桌同时结算时语音会依次播放。Windows 语音组件不可用时会退回不同的系统提示音。

真实订单全局至少间隔 3 秒发送。网站返回 `-96`“投注过于频繁”时，程序会将后续订单再延迟 10 秒；发送前会重新检查桌台局号、下注状态和安全余量，不会补发已经过期的订单。

## 后台运行

关闭主窗口会隐藏到系统托盘，不会退出程序。双击托盘图标可重新打开。托盘菜单可以打开窗口、暂停或恢复自动下单、退出程序。

“暂停自动下单”不会中断已经受理的订单；程序仍会等待结算并保存状态。

## 自动暂停

以下情况会自动暂停真实订单：

- 登录失效或 Chrome/网页连接中断
- 页面运行时接口兼容检查失败
- 网站返回验证码错误 `-140`

余额不足、桌台限额不符或达到资金上限时只跳过不合规订单。单桌订单状态不明时不能在该桌自动补单；请在网站订单记录中人工核对，再处理本地状态。

单个桌台出现订单确认超时或下单状态不明时，程序只隔离该桌；其他桌台继续监控和处理新订单。状态不明订单的金额会继续占用余额、在途上限和每日风险额度。网站稍后返回明确确认时，程序会自动恢复该桌订单状态。页面断线、运行时接口不兼容或验证码等全局问题仍会暂停全部真实新订单。

已明确受理的订单如果在切换牌靴或洗牌前仍未观察到开奖结果，程序会将其改为“待外部结算”，结束旧追注并立即释放该桌。新牌靴可以继续触发和创建新订单；程序不会猜测旧订单输赢，也不会据此进入下一档。旧订单金额继续计入在途和风险额度，网站最终结算后在“订单对账”中选择“确认已结算”即可释放占用。

“启动监控”会恢复上次保存的桌台、追注、未完成订单、当日累计金额和防重复状态。重启时，尚未收到受理结果的订单会变为“状态不明”并隔离对应桌台；已经受理但未观察到结果的订单会变为“待外部结算”，桌台可以继续处理新订单。

确实需要放弃全部旧运行状态时，可以点击“重置状态并启动”。确认后，程序会清空桌台、追注、未完成订单、当日累计金额和防重复状态，再以网页最新全桌数据重新判断；设置、运行日志和订单审计文件不会删除。网页最新结果恰好满足策略触发条件时可能重新生成订单，因此真实模式下必须先在网站确认没有仍在处理的订单。

如果保存策略时提示其他策略仍有未完成订单，请按提示处理：

1. “等待网站确认”表示订单刚发送，等待网站返回结果后再操作。
2. “等待开奖结果”表示订单已经受理，必须等待该局结算。
3. “状态不明”通常由程序重启或确认超时导致。监控运行中也可以点击“订单对账”，逐笔核对网站订单记录后选择“确认未下注”或“确认已结算”；处理后该桌会自动解除隔离。仍在等待结算或无法确认时选择“暂不处理”。
4. “待外部结算”表示订单已经受理，但程序在洗牌、跨靴或重启前没有观察到结果。它不会隔离桌台；网站结算后选择“确认已结算”。

人工对账结果会保存在订单审计记录中。程序不会自动猜测订单结果，也不允许人工清除正常等待网站确认或等待开奖结果的活动订单。

## 本地数据

点击“数据目录”可打开：

```text
%LOCALAPPDATA%\ScreenWatch\yaxin\
```

其中保存非敏感设置、每桌状态、订单审计日志和专用 Chrome 用户目录。程序不会把账号、密码、Cookie 或登录令牌写入日志。
