# 四模式离线回放

双击 `index.html`，在 Windows 或 macOS 的 Chrome、Edge 或 Safari 中使用。所有脚本内嵌，不需要安装依赖、启动服务或联网。它是独立的历史回放工具，不连接网站或监控程序。

1. 勾选一种或多种模式，设置连续同色口数和 1–3 档虚拟积分（默认 `10,20,40`）。
2. 粘贴历史记录，或导入 UTF-8 TXT。每行格式为 `桌名 | 靴号 | 结果`，同桌同靴只写一行。
3. 点击“开始回放”，查看各模式统计与逐口明细；可导出 CSV。

```text
桌A | 1 | 庄庄庄庄庄庄闲
桌A | 2 | 庄闲庄闲庄闲闲闲庄
桌B | 1 | 庄庄闲闲庄庄庄庄闲
桌C | 1 | 庄庄庄闲闲闲庄庄庄庄庄庄
```

结果按旧到新排列，支持 `庄/闲/和` 或 `B/P/T`。最多 50,000 口。输入历史仅用于当前页面，关闭后不保存。

## 判定规则

| 模式 | 首次形成 | 首次模拟方向 |
| --- | --- | --- |
| 连续同色 | 庄庄庄庄庄庄（默认 6 口） | 闲 |
| 单口交替 | 庄闲庄闲庄闲（6 口） | 庄 |
| 两口交替 | 庄庄闲闲庄庄（6 口） | 闲 |
| 三口交替 | 庄庄庄闲闲闲庄庄庄（9 口） | 闲 |

- 庄闲互换后的对应模式同样有效。交替模式要求每段长度严格匹配，不从较长的一段中截取末尾几口匹配。例如 `庄庄庄闲闲庄庄` 不算两口交替。
- 始终选择触发末口的反方向，后续两档保持该方向。命中后结束，未中进入下一档，档位用尽结束。
- 和局在模式识别时忽略；模拟期间退回积分并保持原档位。因此最多三次非和局尝试，实际观察口数可能超过三口。
- 持续延长的同一图案只触发一次，图案打断后重新形成才能再次触发。
- 同一桌靴、同一模式最多一个活动任务；期间出现的新图案消耗该次信号，不排队补触发。多选模式彼此独立，可同时存在任务。
- 只使用触发之后的结果判定命中。每行结束仍未完成的任务记为“数据不足”，不跨靴延续，也不视为失败。
- 积分按 1:1 简化，忽略佣金和其他支付规则。“已结算积分净变化”包括未完成任务中已观察到的损失，不包括尚无结果的下一档。
- 命中率分母为已完成任务（命中 + 档位用尽）。这是输入历史的描述性统计，不代表未来概率。多选结果不可当作同一资金账户合并。
- 提示音仅在回放成功完成时播放，开关即时生效；不是实时信号提醒。
